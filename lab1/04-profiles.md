# Профили пользователей, задач, среды и групп

Профили построены на основе опроса ([03-survey.md](03-survey.md), n=19), анализа конкурентов ([02-competitors.md](02-competitors.md)) и предметной области.

## 1. Профили пользователей

Выделены четыре главные категории пользователей системы: два профиля студентов, преподаватель и администратор платформы.

### Профиль 1. «Самомотивированный студент»

| Раздел | Описание |
|---|---|
| Социальные характеристики | Пол — любой (58% М / 42% Ж); возраст 18-25 лет; студенты технических вузов, желающие прокачать профессиональный навык |
| Навыки и умения | Уверенных пользователей — 79%, есть опыт минимум одной платформы, чаще всего **Stepik (79%) и Яндекс.Практикум (74%)**, Coursera используют реже (37%) |
| Мотивационно-целевая среда | Получить конкретный навык/сертификат; **главный барьер — не нехватка знаний, а потеря мотивации: 58% отмечают это как основную сложность и 84% — как причину, по которой бросили бы курс** |
| Рабочая среда | **Компьютер/ноутбук — основное устройство (95%)**, смартфон использует для обучения лишь 5% — дома (84% занимаются дома) |
| Особенности взаимодействия | Проходит курс частями в свободное время; ценит наглядный прогресс (79%) и хочет получать уведомления (84%) |

### Профиль 2. «Студент по учебной программе»

| Раздел | Описание |
|---|---|
| Социальные характеристики | Возраст 18-25 лет; студент вуза, часть курсов назначена как обязательная (84% используют платформы именно для обязательных курсов вуза) |
| Навыки и умения | Средний/высокий уровень владения компьютером |
| Мотивационно-целевая среда | Прямая учебная необходимость — сдать тесты/задания; 68% проходят начатые курсы лишь «иногда», только 16% — «почти всегда» |
| Рабочая среда | Дома за компьютером — совпадает с Профилем 1 по устройству |
| Особенности взаимодействия | Нуждается в чётких дедлайнах и напоминаниях (84% хотят уведомления о дедлайнах); мало общения с преподавателем и другими студентами — вторая по частоте сложность (47%) |

Профили 1 и 2 на практике описывают не двух разных людей, а два мотивационных режима одного и того же студента: 95% используют платформу для самообразования и одновременно 84% — по требованию вуза. В дизайне интерфейса стоит закладывать переключение между режимами, а не разные сценарии регистрации или отдельные аккаунты.

### Профиль 3. «Преподаватель / автор курса»

| Раздел | Описание |
|---|---|
| Социальные характеристики | Возраст 28-55 лет, высшее образование, преподаватель вуза либо практикующий специалист, ведущий авторский курс |
| Навыки и умения | Уверенное владение офисным ПО, опыт публичных выступлений/лекций, опыт с платформами — от начального до продвинутого |
| Мотивационно-целевая среда | Донести материал до максимального числа студентов с минимальными затратами времени на рутину (проверку однотипных работ); профессиональный престиж |
| Рабочая среда | Рабочий кабинет/дом, ПК, иногда — планшет для проверки работ в дороге |
| Особенности взаимодействия | Работает с большим объёмом материалов и присланных работ; нуждается в инструментах пакетной проверки и статистике по группе, а не по одному студенту |

### Профиль 4. «Администратор платформы»

| Раздел | Описание |
|---|---|
| Социальные характеристики | Сотрудник команды разработки/владельца платформы, ИТ-грамотность выше среднего |
| Навыки и умения | Уверенное владение ПО, опыт модерации контента и работы с учётными системами |
| Мотивационно-целевая среда | Поддерживать качество каталога курсов (без дублей, спама), контролировать нагрузку системы и соблюдение правил площадки |
| Рабочая среда | Офис/удалённо, ПК, стандартизированное ПО |
| Особенности взаимодействия | Работает с большим объёмом данных (десятки курсов, сотни пользователей), нужны инструменты массовой модерации и понятные отчёты |

## 2. Профили задач

| Группа пользователей | Задачи (частота / важность / очерёдность) | Связи между задачами |
|---|---|---|
| Гость | 1) Просмотр каталога курсов (высокая частота) → 2) Просмотр описания курса (высокая) → 3) Регистрация (средняя, при принятии решения) | 1→2→3 — линейная последовательность знакомства с платформой |
| Студент (оба мотивационных режима) | 1) Поиск/выбор курса (высокая, критично) → 2) Запись на курс (высокая) → 3) Изучение материалов по модулям (высокая, критично) → 4) Прохождение тестов (высокая, критично — **89% назвали тесты/задания важнейшей функцией**) → 5) Выполнение и отправка заданий (средняя, критично) → 6) Участие в форуме (средняя, желательно — важно для 32%) → 7) Отслеживание прогресса (высокая — **79%**) → 8) Получение сертификата (средняя — **68%**, финал сценария) | 1→2→3→(4,5 параллельно по модулям)→7→8; 6 — самостоятельная задача, доступна на любом этапе |
| Преподаватель | 1) Создание/редактирование курса и модулей (низкая частота, высокая значимость) 2) Загрузка материалов (средняя) 3) Создание тестов и заданий (средняя, критично) 4) Проверка присланных работ (высокая частота, критично) 5) Ответы в форуме курса (средняя-высокая частота) 6) Просмотр статистики по студентам (низкая-средняя частота) | 1→2→3 — создание курса; 4 и 5 — регулярные операции, зависят от активности студентов; 6 — периодический контроль |
| Администратор | 1) Модерация/публикация новых курсов (средняя частота) 2) Управление категориями каталога (низкая частота) 3) Управление пользователями (низкая-средняя частота) 4) Формирование отчётности по платформе (низкая частота) | 1 может блокировать появление курса в каталоге у гостей/студентов; 2-4 — независимые периодические задачи |

**Задачи, подлежащие реализации в первую очередь:** просмотр каталога и описания курса, запись на курс, изучение материалов, прохождение тестов, отслеживание прогресса — ядро ценности продукта для студента, подтверждённое и требованием варианта задания, и опросом (тесты 89%, прогресс 79%).

**Различия в потребностях пользователей:** для студента (независимо от мотивационного режима) ключевой риск — потеря мотивации и отсутствие обратной связи, а не сложность интерфейса; преподаватель нуждается в скорости массовой проверки работ, а не изяществе интерфейса; администратор — в контроле и отчётности при нечастых, но объёмных операциях.

## 3. Профиль среды

| Характеристика | Признак | Влияние на интерфейс |
|---|---|---|
| Место использования | Преимущественно закрытое пространство, дома (84%); «в разных местах» — у 16% | Основной сценарий — стабильная домашняя сеть; поддержка офлайн-режима — второстепенная функция |
| Рабочее место | Просторное, за компьютером — доминирующий паттерн (95%) | Приоритет полноценного desktop/веб-интерфейса с богатой функциональностью; мобильное приложение — вторичный канал (уведомления, чтение текста, лёгкое повторение) |
| Освещённость | Переменная: от яркого дневного света у окна до тусклого вечером дома | Поддержка тёмной темы, повышенный контраст текста и субтитров видео |
| Аппаратное обеспечение | Разные по мощности ПК/ноутбуки; заметная доля Linux (21%) | Кроссплатформенная поддержка браузеров без завязки на конкретную ОС; адаптивный битрейт для видео |
| Программное обеспечение | Windows 53%, macOS 26%, Linux 21%; смартфон — Android/iOS у единичных пользователей | Веб-часть — приоритет №1 по кроссбраузерности; мобильное приложение может отставать по функциональности от веба на старте без критичной потери ценности |
| Прерывания | Дома прерывания реже, чем в дороге, но растянутость во времени (курс идёт неделями) создаёт риск «забыть про курс» | Нужны уведомления и напоминания (84% хотят их получать) |
| Шумность | Дом — как правило, тихая среда | Не является приоритетным ограничением для данной аудитории |

## 4. Профили групп пользователей

На основе профилей пользователей, среды и задач сформированы группы:

**Группа №1 — «Студенты» (объединяет Профили 1 и 2)**
- 18-25 лет, преимущественно IT/инженерные специальности
- Занимаются дома за компьютером
- Уверенные пользователи цифровых сервисов (79%)
- Главный риск для удержания — потеря мотивации, а не технические сложности
- Самая многочисленная и приоритетная группа — весь MVP ориентирован на неё

**Группа №2 — «Преподаватели/авторы курсов»**
- Внутренние пользователи с регулярной нагрузкой по проверке работ и ответам на форуме
- Приносят бизнесу ценность через качество и актуальность контента платформы

**Группа №3 — «Администраторы платформы»**
- Немногочисленная, но критичная для качества каталога и порядка на платформе группа
